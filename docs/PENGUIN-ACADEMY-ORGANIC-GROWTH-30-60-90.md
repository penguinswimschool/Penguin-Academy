## First 30 days

- Monitor Search Console weekly for impressions, clicks, CTR and the page receiving each priority query.
- Confirm that impressions on legacy redirect URLs move to canonical Academy pages; request recrawling only if stale results persist after the normal consolidation period.
- Identify the single robots-blocked URL and crawled-but-not-indexed URL in the latest indexing report before changing directives.
- Improve titles and descriptions only where a page has meaningful impressions and weak CTR; avoid repeated title changes before Google processes the current migration.
- Strengthen the existing SSI-versus-NROC guide using current official SSI, CoachSG, ActiveSG and Singapore Aquatics sources.
- Add human expert-review attribution only after the named reviewer has genuinely reviewed the article and the review date is recorded.

## Days 31–60

- Compare query-to-page alignment for generic course, Level 1, Level 2, Baby, Adult, React Right, course-date and pathway-comparison clusters.
- Add one evidence-led candidate journey or training-process case study using real, consented facts and photos; do not promise employment or income.
- Earn relevant citations and links from legitimate Penguin, trainer, SSI or aquatic-industry pages where editorially appropriate.
- Review Core Web Vitals field data when enough Search Console data exists; prioritize real failing URLs rather than laboratory scores alone.
- Measure WhatsApp clicks by source, course and candidate segment using the existing tracking events.

## Days 61–90

- Consolidate or re-target any pages competing for the same query rather than publishing overlapping content.
- Refresh high-impression guides with verified changes to standards, dates or official requirements.
- Expand international guidance only where Search Console shows demand or enquiries reveal repeatable country-specific questions.
- Review conversions from organic landing page to course view, course-date view and WhatsApp enquiry.
- Set the next quarterly plan from measured query growth, non-brand clicks, qualified enquiries and canonical-page coverage.

## Guardrails

- All published prices are in SGD.
- Do not claim a number-one ranking, guaranteed job, guaranteed income, universal recognition, funding eligibility or regulatory acceptance without current primary evidence specific to Penguin Academy.
- Do not publish course dates, Event structured data, testimonials or reviewer attribution until the underlying facts are confirmed.
- Keep Penguin Academy as the canonical owner of training and course sales content.
